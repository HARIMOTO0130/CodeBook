# 教师端数据库表比较分析

## 比较对象
- **教师端完整数据库**: `wff_codebook.sql`
- **基础数据库**: `codebook_fixed.sql`

## 1. 教师端相关表在基础数据库中的存在情况

### 1.1 完全不存在的表
以下与教师端功能相关的表在 `codebook_fixed.sql` 中完全不存在：

| 表名 | 功能描述 | 所属模块 |
|------|----------|----------|
| `class` | 班级基本信息 | 班级管理 |
| `class_resource` | 班级教学资源 | 班级管理 |
| `course_design` | 课程设计信息 | 教学管理 |
| `homework` | 作业信息 | 作业管理 |
| `student` | 学生基本信息 | 学生管理 |
| `teacher` | 教师基本信息 | 用户角色管理 |
| `notice` | 通知信息 | 通知系统 |
| `student_homework` | 学生作业提交 | 作业管理 |
| `student_learning_progress` | 学生学习进度 | 学生管理 |
| `student_notice_read` | 学生通知阅读记录 | 通知系统 |

### 1.2 表名相似但功能不同的表
| 表名 | 描述 | 差异 |
|------|------|------|
| `auth_permission` | 权限表 | `wff_codebook.sql` 中包含更多教师端相关权限（如班级、作业、课程设计等管理权限） |

## 2. 表结构差异分析

### 2.1 `auth_permission` 表权限差异
- **codebook_fixed.sql**: 包含基础权限（教材、章节、练习题等），共180个权限
- **wff_codebook.sql**: 在基础权限基础上新增了教师端相关权限（班级管理、作业管理、课程设计等），共277个权限

## 3. 结论

### 3.1 核心差异
`wff_codebook.sql` 相比 `codebook_fixed.sql` 新增了大量与教师端功能相关的表，主要包括：
1. **班级管理模块**：班级信息、班级资源
2. **教学管理模块**：课程设计
3. **作业管理模块**：作业、学生作业提交
4. **学生管理模块**：学生信息、学习进度
5. **通知系统**：通知、学生通知阅读记录
6. **用户角色**：教师信息

### 3.2 数据库升级建议
如果需要将基础数据库升级为支持教师端功能的数据库，需要：
1. 新增上述所有缺失的表
2. 更新 `auth_permission` 表以包含教师端相关权限
3. 确保所有外键关系正确设置

### 3.3 数据迁移注意事项
- 教师信息需要从现有用户系统中迁移或关联
- 学生信息需要重新导入或从现有系统迁移
- 已有的教材和章节信息需要与新的班级和课程设计模块关联
