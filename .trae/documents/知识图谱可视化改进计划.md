# 知识图谱可视化改进计划

## 1. 现有知识图谱可视化分析

当前前端项目在 `LearningPathView.vue` 中已经实现了初步的知识图谱可视化功能，包括：

* SVG-based 知识图谱展示

* 节点选择、高亮、筛选功能

* 层级显示控制

* AI 生成的节点解释和学习建议

但目前存在以下问题：

* 知识图谱数据为模拟数据，未连接真实后端

* 布局算法简单，不支持复杂知识图谱结构

* 交互功能有限，缺乏缩放、平移等高级功能

* 缺乏知识图谱构建过程的可视化

## 2. 知识图谱可视化改进方案

### 2.1 优化现有知识图谱可视化组件

**改进点：**

1. **增强布局算法**

   * 实现力导向布局算法，支持更复杂的知识图谱结构

   * 添加层级布局优化，更好地展示多层次知识架构

   * 支持节点拖拽调整，允许用户自定义布局

2. **丰富交互功能**

   * 添加缩放、平移功能，支持查看大型知识图谱

   * 实现节点搜索和过滤功能

   * 添加关系类型筛选，允许用户查看特定类型的关系

   * 支持知识图谱导出功能（PNG、SVG、JSON）

3. **优化可视化效果**

   * 改进节点和关系的样式设计，提高可读性

   * 添加动态效果，如节点展开/折叠、关系动画

   * 优化颜色编码，更好地表示节点类型和状态

### 2.2 添加知识图谱构建可视化组件

**新增组件：**

1. **知识图谱构建过程可视化**

   * 展示知识点提取、关系识别、关系强度计算的过程

   * 可视化知识图谱的动态构建过程

   * 显示构建过程中的关键指标和统计信息

2. **知识图谱统计分析面板**

   * 展示知识图谱的规模（节点数、关系数）

   * 显示各层级节点分布

   * 展示关系类型分布

   * 提供知识图谱结构分析报告

3. **知识图谱编辑组件**

   * 允许用户手动添加、编辑、删除节点和关系

   * 支持批量导入/导出知识图谱数据

   * 提供知识图谱验证功能，检查知识图谱的完整性和一致性

### 2.3 与后端API集成

**API集成：**

1. 添加获取知识图谱数据的API调用
2. 实现知识图谱的动态更新机制
3. 支持向后端提交知识图谱编辑结果
4. 集成知识图谱构建状态查询功能

## 3. 技术实现计划

### 3.1 技术选型

* 使用现有的Vue 3框架

* 考虑集成D3.js或vis.js等专业图可视化库，替代当前的SVG实现

* 使用axios进行API调用

### 3.2 实现步骤

1. **优化现有知识图谱可视化组件**

   * 改进 `LearningPathView.vue` 中的知识图谱可视化部分

   * 实现力导向布局算法

   * 添加缩放、平移等交互功能

   * 优化节点和关系样式

2. **开发知识图谱构建可视化组件**

   * 创建新的组件 `KnowledgeGraphBuildView.vue`

   * 实现知识图谱构建过程的可视化展示

   * 添加统计分析面板

   * 实现知识图谱编辑功能

3. **与后端API集成**

   * 在 `api.js` 中添加知识图谱相关的API调用

   * 实现知识图谱数据的获取和更新

   * 集成知识图谱构建状态查询

4. **测试和优化**

   * 测试知识图谱可视化在不同规模下的性能

   * 优化交互体验

   * 确保与现有系统的兼容性

## 4. 预期效果

通过以上改进，预期可以实现：

* 更直观、更交互性强的知识图谱可视化

* 清晰展示知识图谱的构建过程

* 提供丰富的统计分析信息

* 支持用户参与知识图谱的构建和编辑

* 与后端真实数据的无缝集成

## 5. 实施优先级

1. 优化现有知识图谱可视化组件（高优先级）
2. 与后端API集成（高优先级）
3. 添加知识图谱统计分析面板（中优先级）
4. 开发知识图谱构建过程可视化（中优先级）
5. 实现知识图谱编辑功能（低优先级）
